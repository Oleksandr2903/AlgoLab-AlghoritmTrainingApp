# AlgoLab Academic

Інтерактивний тренажер з дисципліни «Алгоритми та структури даних» для студентів.
Темний сучасний інтерфейс, покрокова візуалізація та збереження прогресу в `localStorage`.

## Модулі

1. **Арена сортувань** — 6 алгоритмів (Merge, Quick з режимами опорного, Bubble, Insertion, Selection, Counting), покрокове відтворення, буфер пам'яті, журнал дій, графіки, пресети edge-case, таблиця теорії та код C.
2. **Складність T(n) і пам'ять LOC** — симулятор до `N = 10⁹` для задач з лекцій 1–2 та візуалізатор адресації масиву з операціями зсуву.
3. **Рекурсія, стек і бінпошук** — трасування стека викликів, дерево викликів, мемоізація, Ханойські вежі; окрема лабораторія бінарного пошуку з демонстрацією помилок `lo = mid` та переповнення `int`.
4. **Тренажер кроків і тести** — гра «вгадай наступний крок», матриця складності (вправа 5.8) та 25 тестових питань із розбором відповідей.

Службовий модуль **«Лекції 6–10»** відкривається паролем: `Ctrl + Shift + E`, пароль `asd2026`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # перевірка типів + production-збірка
npm run lint     # oxlint
```

## Гарячі клавіші

| Клавіша | Дія |
| --- | --- |
| `1`–`4` | Перемикання модулів |
| `Space` | Старт / пауза поточної симуляції |
| `←` / `→` | Крок назад / вперед |
| `R` | Скинути на початок |
| `T` | Відкрити / закрити конспект і код C |
| `Esc` | Закрити модальне вікно або шторку |

## Стан

Прогрес зберігається під ключем `algolab_academic_state_v2`:
обраний модуль і підрежими, режим пояснень PRO/KIDS, звук, рекорд гри та відповіді тестів.

## Структура

```
src/
  components/
    arena/       Арена сортувань, панелі алгоритмів, плеєр, теорія
    memory/      Симулятор T(n) та візуалізатор LOC
    recursion/   Рекурсія, стек, дерево викликів, бінарний пошук
    trainer/     Гра, матриця складності, тести
    dev/         Розширення курсу (лекції 6–10)
    layout/      Шапка, шорткати, швидкий старт
  data/          Теорія, тести, питання вправи
  lib/           Генератори кроків алгоритмів, стан, звук
```

## Стек

React 19, TypeScript, Vite, Tailwind CSS 3, oxlint.
